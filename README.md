## 💡 Featured Projects

### 1. React Toast Notification System

A reusable notification management system built with React, focusing on scalable state management and component reusability.

**Key Engineering Concepts:**
- Centralized notification management using React Context and `useReducer`.
- FIFO queue management for pending notifications.
- Configurable auto-dismiss and persistent notifications.
- Separation of API and state contexts to reduce unnecessary re-renders.
- Component-level testing using Vitest and React Testing Library.

**Tech Stack:** React.js, JavaScript, Context API, useReducer, Vitest.

### 2. JWT Authentication & Authorization System

A full-stack application focused on implementing secure authentication and authorization workflows.

**Key Engineering Concepts:**
- User authentication and authorization.
- Access token and refresh token management.
- HTTP-only cookies and secure session handling.
- Protected routes and role-based access control (RBAC).
- Backend API validation and security.

**Tech Stack:** React.js, Node.js, Express.js, MongoDB, JWT.
